# Student Database Application System - Backend

A modular FastAPI backend for managing student information with CRUD APIs
and an AI chatbot powered by LangGraph and Google Gemini.

## Status
🚧 Under development - Phase 1 (Project Setup) complete.

## Tech Stack
- Python 3.11+
- FastAPI
- MySQL + SQLAlchemy
- Pydantic
- Google Gemini API (planned)
- LangGraph (planned)
- Docker (planned)
